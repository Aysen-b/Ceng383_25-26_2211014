# CENG 383 - Week 3

ASP.NET Core Razor Pages project.

This project implements a **Student Grade Table**.

Features:

- Student data stored in C# model
- Students kept in a List
- Calculate button computes letter grades
- Grade formula: 40% Midterm + 60% Final

Technologies:

- ASP.NET Core Razor Pages
- C#
- HTML
- CSS
